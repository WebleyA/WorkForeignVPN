ДОПОЛНИТЕЛЬНЫЙ ИНСТРУМЕНТ

Доступность сервисов

Отдельная проверка соединений — можно запустить в любой момент.

Локальная панель проверяет доступность сервисов через сеть контейнера, показывает результат и время каждой проверки, а также внешний IP. Помогает проверить маршруты VPN и отличить проблемы DNS от ошибок подключения.

  • Сайты: yandex.ru:443, google.com:443, lk.big3.ru:443 — HTTPS и ответ HTTP.
  • Без DNS: Яндекс 77.88.55.88:80 и Google 142.251.13.113:443 — соединение напрямую по IP.
  • API без ключей: api.openai.com:443 и api.anthropic.com:443 — доступность /v1/models; ответ 401 означает, что API доступен.
  • Рабочая БД: 10.10.13.98:5432 — TCP и ответ протокола PostgreSQL без входа в базу.
  • Внешний IP: api.ipgeo.ru:443 — IP и страна, api.ipify.org:443 — IP. При раздельной маршрутизации адреса могут отличаться.

Для запуска откройте Docker Desktop и выполните команду в терминале:

macOS · Терминал
docker pull ghcr.io/webleya/connectivity-check:latest && { (sleep 3; open http://127.0.0.1:8765/) & docker run --rm --name connectivity-check -p 127.0.0.1:8765:8765 ghcr.io/webleya/connectivity-check:latest; }
Windows · PowerShell
docker pull ghcr.io/webleya/connectivity-check:latest; if ($LASTEXITCODE -eq 0) { $browserJob = Start-Job { Start-Sleep -Seconds 3; Start-Process "http://127.0.0.1:8765/" }; try { docker run --rm --name connectivity-check -p 127.0.0.1:8765:8765 ghcr.io/webleya/connectivity-check:latest } finally { $browserJob | Wait-Job | Remove-Job } }

Команда скачает образ, запустит контейнер и откроет браузер. Оставьте терминал открытым. Если страница открылась раньше запуска сервера, обновите её или откройте страницу проверки ↗. Для остановки нажмите Ctrl+C в этом терминале; контейнер удалится автоматически. Из другого терминала можно остановить его командой docker stop connectivity-check.
